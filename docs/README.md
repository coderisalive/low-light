# Documentation

This folder contains project-level design and methodology notes.

## Included documents

- `architecture.md`: model design and network structure
- `experimental_protocol.md`: training and evaluation protocol
- `limitations.md`: known limitations and caveats

## How to use this folder

Use these documents together with the main repository README to understand:

- model architecture
- dataset handling rules
- validation protocol
- evaluation constraints
- known weaknesses or trade-offs

For implementation details, check the source code under [datasets/README.md](../datasets/README.md), [models/README.md](../models/README.md), and [scripts/README.md](../scripts/README.md).
